# Contributing to OSS-Practice

Welcome! This repository is for practising the open source workflow.

## How to contribute
1. Open an issue that describes the problem you found.
2. Fork this repository.
3. Create a new branch for your change (never work on main).
4. Make a small, focused change.
5. Commit with a clear message and a sign-off (git commit -s).
6. Push the branch to your fork and open a Pull Request.
7. In the description write "Fixes #<issue number>".
8. Respond politely to review comments.

## Rules
- One Pull Request = one change.
- Do not add phone numbers, emails or other personal details.
- Be respectful in every comment.
